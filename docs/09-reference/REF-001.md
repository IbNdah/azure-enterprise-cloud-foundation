# 1. Executive Summary

As part of the **OneCloud 2030** transformation program, Mandara Global has established an Enterprise Landing Zone as the standardized Azure platform for all current and future cloud workloads.

This reference architecture defines the target platform structure and the relationships between governance, networking, identity, security, monitoring, and application landing zones.

It serves as the blueprint for the Terraform implementation developed in the following project phases.

---

# 2. Purpose

The purpose of this reference architecture is to provide a common architectural model for deploying enterprise workloads on Microsoft Azure.

It enables:

- Consistent platform deployments
- Standardized governance
- Secure workload onboarding
- Reusable infrastructure patterns
- Scalable cloud adoption

---

# 3. Scope

This architecture applies to:

- Azure Tenant
- Management Groups
- Platform Subscriptions
- Landing Zone Subscriptions
- Shared Platform Services
- Enterprise Networking
- Identity Services
- Security Services
- Monitoring Services

---

# 4. Architecture Overview

The Enterprise Landing Zone separates shared platform capabilities from business workloads.

Shared services are centrally managed while application teams deploy workloads into dedicated Landing Zones.

---

The reference architecture aligns with the enterprise architecture principles defined in ARC-001.

Key principles include:

- Platform over Projects
- Infrastructure as Code
- Security by Design
- Zero Trust
- Shared Services First
- Standardization over Customization
