# 1. Executive Summary

As part of the **OneCloud 2030** transformation program, Mandara Global has adopted a centralized enterprise networking model based on Azure Hub & Spoke architecture.

This reference architecture defines the target network topology used to securely connect shared platform services, business workloads, and on-premises environments while maintaining centralized governance and operational control.

---

# 2. Purpose

The purpose of this reference architecture is to provide a standardized network design for all Azure workloads.

It enables:

- Centralized connectivity
- Secure workload isolation
- Simplified network management
- Reusable network patterns
- Scalable cloud expansion

---

# 3. Scope

This architecture applies to:

- Hub Virtual Network
- Spoke Virtual Networks
- Azure Firewall
- VPN Gateway
- ExpressRoute Gateway
- Private DNS
- Private Endpoints
- Virtual Network Peering

---

# 4. Architecture Overview

The network architecture separates shared connectivity services from application workloads.

The Hub Virtual Network provides centralized networking services, while each business workload is deployed into an isolated Spoke Virtual Network.

Communication between spokes is routed through the Hub to enforce security, inspection, and governance.

---

# 5. High-Level Architecture

```text
                    On-Premises
                         │
                VPN / ExpressRoute
                         │
                  Hub Virtual Network
                         │
        ┌────────────────┼────────────────┐
        │                │                │
 Azure Firewall    Private DNS     Bastion Host
        │                │                │
        └────────────────┼────────────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
   Production       Non-Production     Sandbox
     Spoke              Spoke            Spoke
        │                │                │
 Application      Application      Test Workloads
   Resources         Resources
```

---

# 6. Core Components

| Component | Purpose |
|----------|---------|
| Hub VNet | Central networking services |
| Spoke VNets | Isolated workload environments |
| Azure Firewall | Central traffic inspection |
| VPN Gateway | Secure hybrid connectivity |
| ExpressRoute | Private enterprise connectivity |
| Private DNS | Internal name resolution |
| Private Endpoints | Private access to Azure PaaS |
| Bastion | Secure VM administration |

---

# 7. Network Design Principles

The architecture follows the enterprise networking principles defined by Mandara Global.

Key principles include:

- Hub & Spoke topology
- Network segmentation
- Centralized security
- Private connectivity by default
- Least privilege network access
- Shared connectivity services
- Scalable network design
