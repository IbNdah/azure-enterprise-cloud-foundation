# Purpose

This document defines Mandara Global's cloud strategy as part of the OneCloud 2030 transformation program.

It establishes the strategic direction for cloud adoption, defines enterprise cloud objectives, and provides the guiding principles that will shape the Azure Enterprise Cloud Foundation.

This strategy aligns cloud investments with business priorities while ensuring governance, security, operational excellence, and long-term scalability.

---

# Executive Summary

Mandara Global recognizes cloud computing as a strategic business capability rather than a technology initiative.

The OneCloud 2030 program positions Azure as the enterprise cloud platform that will accelerate innovation, improve operational efficiency, strengthen cybersecurity, and provide a scalable foundation for future digital initiatives.

The cloud strategy focuses on building a standardized enterprise platform that enables Business Units to innovate independently while operating within a common governance framework.

---

# Strategic Vision

**Build a secure, governed, scalable, and AI-ready enterprise cloud platform that accelerates business innovation while reducing operational complexity across all Business Units.**

Cloud is not considered the destination.

Cloud is considered the operating model for the future enterprise.

# Cloud Adoption Principles

Mandara Global adopts the following enterprise cloud principles.

| Principle | Description |
|------------|-------------|
| Cloud First | New platforms should be designed for cloud deployment whenever appropriate. |
| Platform over Projects | Shared enterprise platforms take precedence over isolated project implementations. |
| Security by Design | Security is integrated into every layer of the architecture. |
| Governance by Default | Governance controls are built into the platform rather than added later. |
| Automation First | Manual provisioning should be minimized through Infrastructure as Code. |
| Standardization over Customization | Enterprise standards reduce operational complexity. |
| AI Ready | The platform must support future AI capabilities without architectural redesign. |

# Cloud Operating Model

The Azure Enterprise Cloud Foundation will provide shared cloud capabilities to every Business Unit.

```text
Business Units
        │
        ▼
Azure Enterprise Cloud Foundation
        │
 ┌──────┼────────┬─────────┬──────────┐
 │      │        │         │
Identity Network Security Governance Monitoring
        │
        ▼
Shared Enterprise Services
```

Business Units consume standardized cloud services instead of independently building cloud infrastructure.

---

# Success Metrics

The OneCloud 2030 cloud strategy will be considered successful when:

- Enterprise governance is consistently applied across all subscriptions.
- Infrastructure deployments are fully automated using Terraform.
- Cloud environments can be provisioned within hours rather than days.
- Security controls are standardized across all Business Units.
- Cloud costs are transparent and measurable.
- The platform supports future AI initiatives without major redesign.
